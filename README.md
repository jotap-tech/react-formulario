React Formulário Controlado

Aplicação desenvolvida em React como atividade acadêmica da disciplina Frontend Frameworks, do curso de Sistemas de Informação.

O projeto consiste na criação de um formulário controlado contendo os campos Nome, Email e Mensagem. Após o envio, os dados preenchidos são exibidos na tela abaixo do formulário.

Tecnologias

React — desenvolvimento da interface e gerenciamento do estado do formulário.

JavaScript — lógica e manipulação dos dados.

Funcionalidades

Formulário controlado utilizando React.

Campo para nome.

Campo para email.

Campo para mensagem.

Captura dos dados através do estado da aplicação.

Exibição dos dados enviados abaixo do formulário.

Como executar

Clone o repositório:

git clone https://github.com/SEU-USUARIO/react-formulario-controlado.git


Acesse a pasta do projeto:

cd react-formulario-controlado


Instale as dependências:

npm install


Execute a aplicação:

npm run dev


A aplicação estará disponível no endereço informado pelo Vite no terminal.

Objetivo

O objetivo da atividade é aplicar os fundamentos de formulários controlados no React, utilizando estados e eventos para capturar, controlar e exibir os dados inseridos pelo usuário.
